Atividade 1 - comentário:
Entendo pelo texto que a Engenharia de Software difere-se do termo programação no geral, percorrendo conceitos mais elaborados e seguindo práticas de Desenvolvimento de Software estabelecidas para uma entrega sólida, documentada e compreensível. Além disso, o conceito de Engenharia de Software está constantemente sendo preenchido por novas ideias e expandindo seus limites de demonstração, pois como dito no texto, o Software necessita cada vez maior rigidez e qualidade, penso que como consequência de dialogar cada vez mais com o cotidiano da pessoa comum.

Atividade 2 - comentário:
A Engenharia de Software é o nome dado a todo o processo de construção e manutenção de uma aplicação ou serviço. Penso que para o objetivo de um código escalável, longevo e de alta manutenibilidade como citado no texto, um dos princípios que a Engenharia de Software deve seguir é o de Alta Coesão e Baixo Acoplamento entre funções, entidades e módulos das aplicações, além de princípios de código limpo e constante revisão de código.
